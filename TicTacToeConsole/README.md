# Tic-Tac-Toe (Console Edition)

A simple Tic-Tac-Toe game developed in C# as part of my programming learning journey.

## Project Overview

This project was created while learning object-oriented programming and core C# concepts. The main goal was not only to build a working game but also to understand the logic behind it and practice writing structured code.

The game currently runs in the console and supports two human players taking turns.

## Features

* 3x3 game board
* Turn-based gameplay
* Win detection

  * Rows
  * Columns
  * Main diagonal
  * Anti-diagonal
* Draw detection
* Game state management
* Event-driven architecture
* Object-oriented design

## Concepts Practiced

* Classes and objects
* Properties
* Enums
* Events and delegates
* Two-dimensional arrays
* Methods and encapsulation
* Game state management
* Conditional logic
* Basic software architecture
