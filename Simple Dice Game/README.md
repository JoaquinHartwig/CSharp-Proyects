# 🎲 Simple Dice Game

A simple console-based dice game developed in C# as part of my programming learning journey.

## Overview

This project simulates a dice battle between the player and an AI opponent.

The game consists of 10 rounds. During each round:

* The player rolls a dice.
* The AI rolls a dice.
* The highest number wins the round.
* The winner earns one point.
* If both numbers are equal, the round ends in a draw.

At the end of the game, the player with the highest score wins.
