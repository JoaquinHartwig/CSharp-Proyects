# Calculator

> My first complete C# project after finishing my C# learning course.

## About

This project is a calculator developed in C# as part of my transition from learning concepts to building complete applications.

The goal of this project is to apply the programming concepts learned during my studies, including object-oriented programming, methods, control structures, validation, and user interaction.

---

## Features

Current features:

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Error handling

Planned features:

- Power calculations
- Square roots
- Percentage calculations
- Calculation history
- Improved user interface

## Concepts Practiced

- Classes and objects
- Encapsulation
