# Development Log

## 10/06/2026

### Project Started

Today I started my first complete C# project after finishing my C# learning course.

The project is a simple console calculator that performs the four basic arithmetic operations:

* Addition
* Subtraction
* Multiplication
* Division

The user enters two numbers, selects an operation, and the program displays the result.

---

### Current Features

Implemented:

* User input through the console.
* Addition.
* Subtraction.
* Multiplication.
* Division.
* Division by zero validation using `float.NaN`.
* Basic user interaction.

---

This project helped me review and apply several concepts learned during my studies:

### Challenges

Since I spent several weeks focusing on university subjects and programming in C, I noticed that I became somewhat rusty with C# syntax.

Building this calculator has been a good opportunity to reconnect with the language and reinforce concepts that I had not used recently.

---

### Current Limitations

The calculator is functional, but there are several areas that can be improved:

* No exception handling for invalid user input.
* Only one operation can be performed before the program closes.
* No menu loop.
* No operation history.
* No use of classes besides `Program`.
* No object-oriented design yet.
