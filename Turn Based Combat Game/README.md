# Turn Based Combat Game

## About the Project

Turn Based Combat Game is a personal C# project created to practice Object-Oriented Programming and improve my software development skills.

The project started as a simple console application featuring a basic turn-based battle system between a player and an enemy. While the current version is relatively simple, the main goal is to continuously improve and expand the game as I learn new C# concepts and programming techniques.

This repository serves both as a learning project and as a record of my progress as a developer.

---

## Current Features

* Turn-based combat system
* Player and enemy units
* Randomized damage calculation
* Healing mechanics
* Health management (Current HP / Max HP)
* Defeat detection
* Basic enemy AI
* Console-based gameplay
* Object-Oriented design using classes and methods
