# 🐍 Retro Snake Game

A classic Snake game built in C# using the console.

This project was created as part of my C# learning journey to practice Object-Oriented Programming, game loops, collections, keyboard input, collision detection, and game state management.

---

## 🎮 Features

* Real-time snake movement
* Random apple spawning
* Growing snake tail
* Score tracking
* Wall collision detection
* Self-collision detection
* Automatic game restart after death
* WASD controls
